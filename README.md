## Frontend Setup (running from source)

1. Navigate into the frontend folder:
   ```
   cd frontend
   ```
2. Install dependencies:
   ```
   npm install
   ```

4. Run the app locally:
   ```
   npm run dev
   ```
5. To create a new production build:
   ```
   npm run build
   ```
   This generates a `dist` (or `build`) folder that can be deployed as static files.
